# Blue-Print 1.0.0

Blue-Printの初回安定版です。Macのローカルデータを正本として、記帳、
証憑管理、請求・支払、決算、青色申告準備、弥生移行、暗号化バックアップを
一つのアプリで扱えます。

## 主な機能

- 複式簿記の仕訳、試算表、損益計算書、貸借対照表
- 証憑原本の保存、オンデバイスOCR候補、仕訳との関連付け
- 請求書・支払・消込、固定資産、家事按分、棚卸
- 2025年分の青色申告決算書とe-Tax用`.xtx`出力
- 弥生形式の仕訳・期首残高移行
- 全データ出力、暗号化バックアップ、診断
- VoiceOverラベル、キーボードショートカット、案2で統一した画面デザイン

## 対応環境

- macOS 14 Sonoma以降、Apple Silicon
- 正式検証: macOS 26 / Xcode 26.2 / Swift 6.2
- Intel Macは対象外

## 対応年度・形式

- 2025年分の事業所得・不動産所得用青色申告支援
- 給与、株式、配当、その他所得の年度集約
- 弥生デスクトップ／オンライン25列仕訳
- 弥生会計 Next 25／27列仕訳、6列期首残高
- Blue-Print DBスキーマ9、持ち出し形式8

## インストール

1. `BluePrint-macOS-arm64.zip`と同名の`.sha256`をダウンロードする。
2. 同じフォルダで次を実行し、`OK`を確認する。

```sh
shasum -a 256 -c BluePrint-macOS-arm64.zip.sha256
```

3. ZIPを展開し、`BluePrint.app`をApplicationsフォルダへ移動して起動する。

## 既知の制限

- 対応申告年度は2025年分のみ。制度・帳票の年度更新は別リリースで行う。
- Intel Macは正式対象外。
- `.xtx`には一般用と不動産所得用の青色申告決算書を収録する。該当しない
  帳票を含め、送信前にe-Tax WEB版で年度、本人情報、所得、控除、決算金額を
  必ず確認する。
- e-Tax WEB版でのファイル読込と帳票展開は確認済みだが、同環境でPDF表示が
  長時間完了しなかったため、PDF内容の実地照合はv1.0.0受入に含めていない。
- OCRは確認候補を生成する機能であり、税務判断や仕訳を自動確定しない。
- 自動バックアップはパスフレーズをKeychainへ登録した後に有効になる。
- 自動更新は行わない。新しい版はGitHub Releasesから手動で取得する。

本アプリは税務判断や税理士業務を代替しない。申告内容は利用者または税理士が
確認し、電子署名と送信はe-Tax WEB版で行う。
