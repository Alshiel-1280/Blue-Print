# Blue-Print v2.0.0 release notes

## Summary

Blue-Print v2.0.0 starts a new, sandboxed storage generation. It preserves the
product boundary—one Mac, one sole proprietor, local-first operation, and
handoff to e-Tax WEB—while replacing the runtime architecture and daily work
surface.

## Included

- work-oriented navigation: Home, Daily Work, Books, Closing, and Filing;
- home blockers and explicit next actions;
- normalized SQLite schema owned by one database actor;
- evidence import, immutable originals, on-device OCR candidates, and
  duplicate-hash rejection;
- bank/card CSV preview, normalized import candidates, quarantined rows, and
  evidence matching by date, amount, and counterparty;
- journal templates, recurring schedules, journal rules, pending candidates,
  bulk review, and explicit confirmation;
- normalized counterparties, invoices, settlements, closing decisions, and
  audit history;
- explicit invoice issue with generated PDF evidence and receivable/revenue
  posting, plus full receipt settlement and receipt posting;
- persistent, idempotent jobs with progress, checkpoint, and failure reason;
- persistent XTX generation that resumes failed/interrupted work, reuses an
  identical successful result, and recreates a missing durable output;
- diagnostic findings and repair preview, with encrypted backup before a
  single-transaction repair;
- signed `.bprules` annual packages and a per-scope support matrix;
- Argon2id/AES-256-GCM v2 backups and staged restore;
- user-triggered, signed update-manifest checks;
- App Sandbox, Hardened Runtime release path, signed/notarized DMG tooling.

## Compatibility

v2 does not open, import, copy, migrate, or delete v1 data. The v2 root is
`Application Support/BluePrint-v2`, storage generation 2, schema 1. v2 accepts
only backup family `blueprint-v2`, version 1.

Keep a v1 application and its backups if historical v1 data must remain
viewable. Blue-Print v2 intentionally provides no v1 viewer.

## Annual support

2025 supports bookkeeping, consumption tax, closing, income-tax forms, and
XTX through the retained signed golden rules.

2026 supports bookkeeping, consumption tax, and closing. 2026 income-tax forms
and XTX are disabled. They will be enabled only by a later signed rule package
after final form/schema publication, e-Tax WEB import, general and real-estate
PDF field comparison, re-import, and error-display verification.

## Deferred

iPhone receipt transfer and third-party plugin execution are not included.
Versioned, side-effect-free `ImportCandidateV1`, `ExportSnapshotV1`, and capture
envelope contracts reserve the future boundary without loading external code
or accepting third-party tax-rule replacement.

## Release verification

Repository tests and local ad-hoc package verification are recorded in
`docs/verification/v2.0.md`. An official release is not complete until a
Developer ID-signed, notarized, stapled DMG passes Gatekeeper for both the DMG
and the contained app, and the app launches on a clean second Mac.
