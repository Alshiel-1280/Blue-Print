# ADR-009: 証憑・バックアップ暗号化の境界

- 状態: 採用
- 日付: 2026-07-21
- 対象: NFR-SEC-001〜003、FR-BKP-003

## 判断

ローカル正本は macOS の FileVault、ユーザー権限、App Sandbox/Data Protection を前提とし、v1 初期版では証憑ごとの独自暗号化を必須にしない。アプリ独自鍵を導入する場合は Keychain に保存する。

持ち出されるバックアップは必ず認証付き暗号化する。Argon2公式C実装
20190702を固定同梱し、Argon2id v19、64MiB、3反復、並列度1、16バイトsalt、
32バイト鍵で導出し、AES-256-GCMでDBと証憑を一体保護する。読み込み前に
KDF上限を検証する。

v1.1互換リーダーは旧形式を明示復元時だけ読み、v2の公開復元経路は
`blueprint-v2` family以外を復号前に拒否する。
