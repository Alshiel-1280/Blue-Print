# ADR-007: 年度・帳票ルールの配布

- 状態: 採用
- 日付: 2026-07-21
- 対象: NFR-MNT-002、006、FR-OSS-004

## 判断

年度ルールと帳票ルールはアプリコードから分離した版付き JSON とし、公開後の版を上書きしない。各セットは ID、対象年度、適用期間、スキーマ版、根拠 URL、確認日、内容ハッシュを持つ。

公式ルールは `<year>.bprules` ディレクトリパッケージとし、
`manifest.json`、`payload.json`、`signature.ed25519`を含む。署名は
Ed25519、payloadハッシュはSHA-256とし、埋込み公開鍵で未知鍵、署名欠落、
1バイト改変、旧revision、対象外年度を拒否する。秘密鍵はmacOS Keychainまたは
CI secretだけで扱い、リポジトリへ置かない。

ルールは記帳、消費税、決算、所得税帳票、XTXのスコープ別に有効化する。
2026年の所得税帳票とXTXは実データ受入条件が満たされるまでスコープに含めない。
